# Тихий час

Таймер вимкнення та перезавантаження для Windows. Режим **«Через»** запускає відлік на задану тривалість, а **«О конкретній годині»** планує дію на вибраний час. Прокрутка годин через опівніч змінює дату.

**«Пауза»** зберігає залишок часу, а **«Продовжити»** запускає відлік із цього залишку. **«Скасувати»** завершує поточний відлік. Збережи відкриті файли перед запуском, оскільки Windows може примусово закрити програми.

## Запуск із коду

Потрібен Python із підтримкою Tkinter.

```powershell
python src/shutdown_timer.py
```

## Збірка для Windows

```powershell
python -m pip install pyinstaller
python -m PyInstaller packaging/ShutdownTimer.spec
```

Готовий файл з’явиться у `dist/ShutdownTimer.exe`.
